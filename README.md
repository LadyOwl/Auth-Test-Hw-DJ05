# 🔐 Auth-Test-Hw-DJ05

Учебный Django-проект с кастомной системой аутентификации. Проект демонстрирует, как создать собственную модель пользователя с входом по email вместо стандартного username.

## ✨ Возможности

### 👤 Кастомная модель пользователя
- Вход по **email** вместо username
- Дополнительное поле **phone_number** для хранения телефона
- Наследование от `AbstractUser` для сохранения всей стандартной функциональности Django

### 🔒 Система аутентификации
- **Регистрация** с кастомной формой `CustomUserCreationForm`
- **Вход** в систему через email и пароль
- **Защищённая страница профиля** — доступна только авторизованным пользователям
- Автоматический редирект на страницу входа при попытке доступа к защищённым страницам

### 🎯 Основные страницы
- 🏠 **Главная** (`/`) — публичная страница
- 📝 **Регистрация** (`/register/`) — создание нового аккаунта
- 🔑 **Вход** (`/login/`) — авторизация в системе
- 👤 **Профиль** (`/profile/`) — личная страница пользователя (требует авторизации)

## 🛠️ Технологии

- **Python 3.13.3** — основной язык
- **Django 5.1.5** — веб-фреймворк
- **SQLite** — база данных (по умолчанию)
- **HTML/CSS** — шаблоны и стили

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/LadyOwl/Auth-Test-Hw-DJ05.git
cd Auth-Test-Hw-DJ05
```

### 2. Создайте виртуальное окружение

```bash
# Для Windows
python -m venv venv
venv\Scripts\activate

# Для macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости

Django уже должен быть установлен. Если нет, выполните:

```bash
pip install django
```

### 4. Примените миграции

База данных уже создана (`db.sqlite3`), но если хотите сбросить её и создать заново:

```bash
# Удалите файл db.sqlite3 (опционально)
python manage.py makemigrations
python manage.py migrate
```

### 5. Создайте суперпользователя (опционально)

```bash
python manage.py createsuperuser
```

Следуйте инструкциям и введите email, username и пароль.

### 6. Запустите сервер разработки

```bash
python manage.py runserver
```

### 7. Откройте в браузере

Перейдите по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## 📱 Использование

### Регистрация нового пользователя
1. Перейдите на главную страницу
2. Нажмите ссылку "Register" или перейдите по адресу `/register/`
3. Заполните форму:
   - Email (обязательно, используется для входа)
   - Username (обязательно)
   - Phone number (опционально)
   - Password и подтверждение пароля
4. После успешной регистрации вы будете перенаправлены на страницу входа

### Вход в систему
1. Перейдите на страницу `/login/`
2. Введите email и пароль
3. После успешного входа вы попадёте на страницу профиля

### Доступ к профилю
- Страница `/profile/` доступна только авторизованным пользователям
- Если вы не авторизованы, будете автоматически перенаправлены на страницу входа

## 🔧 Ключевые настройки

### Модель CustomUser (main/models.py)

```python
class CustomUser(AbstractUser):
    email = models.EmailField(unique=True)
    phone_number = models.CharField(max_length=15, blank=True, null=True)
    
    USERNAME_FIELD = 'email'  # Используем email для входа
    REQUIRED_FIELDS = ['username']  # username всё ещё требуется
```

### Настройки аутентификации (auth_test_hw/settings.py)

```python
AUTH_USER_MODEL = 'main.CustomUser'  # Указываем кастомную модель пользователя
LOGIN_URL = 'login'  # URL для перенаправления неавторизованных пользователей
```
